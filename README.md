# React Sandbox

React を静的環境で練習できる Sandbox アプリケーション。

## 特徴

- ブラウザ上で React コードを編集・実行
- リアルタイムプレビュー
- TypeScript サポート
- TDD によるテストカバレッジ

## 開発

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動
npm run dev

# テスト実行
npm test

# ビルド
npm run build
```

## 技術スタック

- React 18
- TypeScript
- Vite
- Vitest + React Testing Library
- GitHub Pages

## CI/CD

GitHub Actions による自動テスト・デプロイ
